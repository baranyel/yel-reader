# Data files

`wordRank.txt` — the 12,000 most frequent English words (one per line, most frequent first;
line number = frequency rank). Used offline to estimate which words are probably new to a reader.

Derived from [wordfreq](https://github.com/rspeer/wordfreq) (Robyn Speer et al.), whose data is
licensed [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). This file is shared under
the same licence.
